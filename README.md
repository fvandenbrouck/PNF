# PNF — Pilotage du Plan National de Formation

Application web pour la gestion du Plan National de Formation continue (DGESCO A3-1) : un ensemble de widgets Grist personnalisés, servis via GitHub Pages et attachés aux différentes pages du document Grist de suivi.

📖 **Documentation complète : [docs/README.md](docs/README.md)** — architecture technique, modèle de données, droits d'accès, référence de chaque widget, historique de construction du projet.
